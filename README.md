# gendlessh

Endlessh in Go

## usage

```
Usage of ./endlessh:
  -addr string
        Bind to this address (default "0.0.0.0:2222")
  -delay uint
        Number of seconds to wait betweem each write (default 10)
  -maxclient uint
        Max amount of connected clients (default 50)
```

## install

You can install `endlessh` by doing: `go install github.com/4zv4l/endlessh@latest`.

## build

Simply `clone` this repo then `go build .`.
